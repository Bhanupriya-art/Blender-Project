# Blender-Project

This repository contains my Blender practice files and projects. I am currently learning Blender and exploring 3D modeling, basic animation, and shape design.
## About
I started this journey to improve my 3D design skills and understand how to work with objects, materials, lighting, and simple animations in Blender. Each file in this repository represents a small project or practice session.
## Goal
My goal is to practice regularly and build a strong foundation in Blender by:
- Modeling basic shapes and objects
- Applying materials and textures
- Learning simple animation
- Working on small creative projects

I will continue to update this repository as I make progress.
